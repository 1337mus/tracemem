These systems and benchmarks address different parts of memory. The benchmark
scores are not evidence that one extraction method is better than another.
Any comparison needs matched histories, retrieval and model budgets, and a
scoring procedure that checks evidence support as well as answer quality.

## TraceMem test

The working hypothesis is that specialized extraction may improve evidence
support, attribution, and temporal fidelity against the same base model, then
improve matched-budget QA. Equal performance from prompt-only extraction or
transcript hybrid RAG would disconfirm the need for fine-tuning. Evidence
citations are integrity anchors, not formal proofs.

## Rights notes

LongMemEval's checked repository license is MIT, but repository licensing alone
does not complete review of its data sources. LoCoMo's article uses CC BY-NC-SA
4.0, while Appendix B.2 and the repository `LICENSE.txt` state CC BY-NC 4.0 for
the dataset. This resolves the apparent article-versus-dataset difference, but
does not establish rights for every referenced conversation, image, caption,
or persona source, or dataset suitability for training.
